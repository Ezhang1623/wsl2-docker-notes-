# WSL2 + Docker Desktop 学习笔记

个人学习笔记：记录在 Windows 上配置 WSL2 和 Docker Desktop 的过程、问题和解决方案。

## 这个仓库是什么
- 个人学习笔记
- 安装与配置踩坑记录
- 常用命令与排查思路

## 不包含什么
- 不提供任何官方安装包文件（如 .msi、.exe）
- 不提供破解、激活、绕过授权的内容
- 不复制他人教程原文
